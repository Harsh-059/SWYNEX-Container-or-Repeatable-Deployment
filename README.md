
# SWYNEX CI Pipeline

## Project Overview
This project demonstrates Continuous Integration (CI)
using GitHub Actions.

## Technologies Used
- Git
- GitHub
- GitHub Actions
- Ubuntu Linux
- Bash Scripting

## Project Features
- Automated workflow execution on every push
- Bash syntax validation
- Automated application execution
- Automated calculator testing
- Pull request validation
